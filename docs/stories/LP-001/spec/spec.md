## 1. Overview

Landing page estática para a consultoria online do **Faggioni Personal Studio**, construída com HTML e CSS puros. O objetivo é converter visitantes vindos do Instagram/Reels em contatos no WhatsApp, apresentando a consultoria de personal trainer online de forma profissional e persuasiva.

### 1.1 Goals

- Apresentar o Faggioni Personal Studio como referência profissional em consultoria online _(FR-7, FR-1)_
- Converter visitantes em contatos via WhatsApp com mensagem pré-preenchida _(FR-8, FR-9)_
- Entregar experiência otimizada para mobile — público vem do Instagram _(NFR-2, ASM-1)_
- Demonstrar resultados reais com fotos autênticas do studio e alunos _(FR-5)_
- Apresentar preço e plano de forma transparente para filtrar leads qualificados _(FR-6)_

### 1.2 Non-Goals (fora do escopo V1)

- Sistema de pagamento ou matrícula online _(CON-3)_
- Formulário de captação de e-mail ou CRM _(CON-3)_
- Backend, banco de dados ou servidor _(CON-1, CON-2)_
- Blog, área de alunos ou conteúdo dinâmico _(CON-1)_
- Múltiplos planos de preço ou variações de desconto _(CON-4)_
- JavaScript — página funciona 100% sem JS _(NFR-3)_

## 3. Abordagem Técnica

### 3.1 Arquitetura

Página estática com dois arquivos principais. Nenhuma dependência externa.

```
faggioni-landing/
├── index.html          ← estrutura semântica completa
├── style.css           ← todos os estilos (mobile-first)
└── imagens/
    ├── hero.jpg        ← foto principal (hero section)
    ├── sobre.jpg       ← foto do Hendrew
    └── resultado-*.jpg ← fotos de alunos (quantas tiver)
```

### 3.2 Estrutura HTML (ordem das seções)

Baseado em FR-1 a FR-9 na sequência de maior impacto para conversão:

```
<header>         → navegação mínima + logo
<section#hero>   → FR-1: headline + subheadline + CTA
<section#problema> → FR-2: dor do público
<section#como-funciona> → FR-3: 3 passos
<section#diferenciais>  → FR-4: diferenciais
<section#resultados>    → FR-5: fotos de alunos
<section#plano>         → FR-6: preço + o que inclui
<section#sobre>         → FR-7: Hendrew + credenciais
<section#cta-final>     → FR-8: CTA WhatsApp final
<footer>                → informações mínimas
<div.botao-flutuante>   → FR-9: WhatsApp sempre visível
```

### 3.3 Paleta de Cores

Derivado da escolha: **preto + branco limpo (minimalista)**

```css
:root {
  --cor-primaria: #0d0d0d;      /* preto principal */
  --cor-secundaria: #ffffff;    /* branco */
  --cor-fundo: #f8f8f8;         /* cinza muito claro para seções alternadas */
  --cor-texto: #1a1a1a;         /* texto corpo */
  --cor-texto-suave: #666666;   /* texto secundário */
  --cor-acento: #25D366;        /* verde WhatsApp — único acento de cor */
}
```

### 3.4 CTA WhatsApp

Link `href` puro — sem JavaScript:

```html
<a href="https://wa.me/55SEU_NUMERO?text=Ol%C3%A1%20Hendrew!%20Vi%20seu%20site%20e%20tenho%20interesse%20na%20consultoria%20online."
   target="_blank"
   rel="noopener noreferrer">
  Falar com Hendrew
</a>
```

> ⚠️ **OQ-1 BLOQUEANTE:** Substituir `SEU_NUMERO` pelo número real antes do deploy _(ASM-2)_

### 3.5 Responsividade

Mobile-first conforme `.claude/rules/css-standards.md`:

| Breakpoint | Largura | Comportamento |
|------------|---------|---------------|
| Mobile (base) | < 768px | Layout em coluna única, fonte base |
| Tablet | ≥ 768px | Grid 2 colunas em algumas seções |
| Desktop | ≥ 1024px | Conteúdo centralizado, max-width: 1100px |

## 6. Estratégia de Testes

Para HTML + CSS estático sem JavaScript, os testes são verificações visuais e funcionais no navegador.

### 6.1 Testes de Aceite (Given-When-Then)

```gherkin
Feature: Landing Page Faggioni Personal Studio

  Scenario: Hero exibido com headline e CTA visível [FR-1]
    Given visitante acessa faggioni-landing/index.html
    When a página carrega no celular (375px)
    Then a seção Hero é a primeira seção visível
    And o botão CTA do WhatsApp está visível acima da dobra

  Scenario: Seção Problema exibe conteúdo de dor do público [FR-2]
    Given visitante está na landing page
    When faz scroll até a seção Problema
    Then pelo menos 3 pontos de dor são exibidos
    And o conteúdo é legível (fonte mínima 16px)

  Scenario: Como Funciona exibe 3 passos numerados [FR-3]
    Given visitante está na landing page
    When faz scroll até a seção Como Funciona
    Then exatamente 3 passos numerados são exibidos
    And cada passo tem título e descrição

  Scenario: Diferenciais exibem pontos únicos da consultoria [FR-4]
    Given visitante está na landing page
    When faz scroll até a seção Diferenciais
    Then pelo menos 3 diferenciais são exibidos
    And cada diferencial tem ícone ou destaque visual

  Scenario: Resultados exibem fotos reais de alunos [FR-5]
    Given visitante está na landing page
    When faz scroll até a seção Resultados
    Then pelo menos 1 foto de aluno é exibida
    And cada foto tem atributo alt descritivo

  Scenario: Seção Sobre exibe foto e bio do Hendrew [FR-7]
    Given visitante está na landing page
    When faz scroll até a seção Sobre Mim
    Then a foto do Hendrew é exibida
    And credenciais ou formação estão presentes no texto

  Scenario: CTA WhatsApp abre com mensagem pré-preenchida [FR-8, INT-1]
    Given visitante está na landing page
    When clica em qualquer botão "Falar com Hendrew"
    Then WhatsApp abre (app ou web) com mensagem pré-preenchida
    And mensagem contém "Olá Hendrew! Vi seu site e tenho interesse na consultoria online."

  Scenario: Página funcional em mobile [NFR-2, EC-4]
    Given acesso via celular com viewport 375px
    When a página carrega
    Then nenhum texto está cortado ou fora da tela
    And todos os botões são clicáveis (mínimo 44x44px de área de toque)
    And imagens não ultrapassam a largura da tela

  Scenario: Botão flutuante visível durante scroll [FR-9]
    Given visitante está em qualquer seção da página
    When faz scroll para cima ou para baixo
    Then o botão flutuante do WhatsApp permanece visível no canto inferior direito

  Scenario: Preço exibido corretamente [FR-6, CON-4]
    Given visitante está na seção de plano
    When visualiza o plano
    Then o preço R$ 99,90/mês é exibido claramente
    And não há outros planos ou variações de preço

  Scenario: Imagens com alt text [NFR-5]
    Given qualquer imagem da página
    When inspecionada no HTML
    Then possui atributo alt com texto descritivo não vazio

  Scenario: Página carrega sem JavaScript [NFR-3]
    Given JavaScript desabilitado no navegador
    When a página é acessada
    Then todos os conteúdos aparecem normalmente
    And todos os links de WhatsApp funcionam
```
