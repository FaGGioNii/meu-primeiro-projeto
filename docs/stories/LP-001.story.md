## Story

**As a** visitante que veio do Instagram do Faggioni Personal Studio,
**I want** ver uma página clara e persuasiva sobre a consultoria online,
**so that** eu entenda o que está incluso, confie no profissional e entre em contato pelo WhatsApp para contratar.

## Acceptance Criteria

1. A página possui as 8 seções na ordem correta: Hero, Problema, Como Funciona, Diferenciais, Resultados, Plano, Sobre Mim, CTA Final.
2. O botão de WhatsApp em todos os CTAs abre `wa.me` com mensagem pré-preenchida: "Olá Hendrew! Vi seu site e tenho interesse na consultoria online."
3. O botão flutuante de WhatsApp permanece visível durante todo o scroll da página.
4. A seção Plano exibe o preço R$ 99,90/mês (plano trimestral) sem variações ou outros planos.
5. Todas as imagens possuem atributo `alt` descritivo e não vazio.
6. O layout funciona sem quebras em viewport de 375px (mobile) e 1280px (desktop).
7. A página não utiliza JavaScript — funciona 100% com JS desabilitado.
8. Nenhum framework externo é utilizado — apenas HTML e CSS nativos.
9. A paleta de cores segue o esquema preto + branco limpo com verde WhatsApp como único acento.
10. Todos os arquivos estão dentro da pasta `faggioni-landing/`.

### Regras CSS a seguir (`.claude/rules/css-standards.md`)
- Mobile first: estilos base para mobile, `min-width` para expandir
- Breakpoints: 768px (tablet), 1024px (desktop)
- Classes em português com hífen: `.botao-whatsapp`, `.secao-hero`, `.card-resultado`
- Nunca usar `!important`

### Regras HTML a seguir (`.claude/rules/html-standards.md`)
- `<html lang="pt-BR">`
- Elementos semânticos: `<header>`, `<main>`, `<section>`, `<footer>`
- Toda `<img>` com `alt` descritivo
- Nunca usar `style=""` inline

### Imagens
- Tamanho máximo: 200KB por imagem
- Formato: JPG ou WebP
- O dev deve criar placeholders comentados para imagens ainda não disponíveis:
  ```html
  <!-- PLACEHOLDER: substituir por foto real -->
  <img src="imagens/resultado-01.jpg" alt="Aluno do Faggioni Personal Studio após 3 meses de treino">
  ```
